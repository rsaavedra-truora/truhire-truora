Truora product icons built from the logo's curves — identity validation, background checks, customer engagement, e-signature.

```jsx
import { ProductIcon } from '@raandino/atelier-react';

<ProductIcon name="identidad" badge size={48} />
<ProductIcon name="verificacion" color="var(--brand)" size={32} />
<ProductIcon name="engagement" badge size={48} />
<ProductIcon name="firma" color="var(--midnight)" size={32} />
```

Names: `identidad` · `verificacion` · `engagement` · `firma`. `badge` renders the manual's presentation (violet rounded square, white glyph). For engagement, `accent` colors the check (defaults to the badge color → knockout look). Raw SVGs: `assets/product-icons/`.
