Circular user avatar with photo or initials fallback and optional presence dot.

```jsx
import { Avatar } from '@raandino/atelier-react';

<Avatar name="María López" size="md" status="online" />
<Avatar name="Ana Rivera" src="/team/ana.jpg" size="lg" />
```

Sizes xs 28 · sm 36 · md 44 · lg 56 · xl 72. `status`: online/busy/away/offline.
